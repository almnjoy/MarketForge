# MoneyTrader - the swing brain (CANONICAL)

One page. This is the file the copilot reads first when a question routes here.

## What this brain trades
Multi-week swing on daily bars. Long, and short when the venue allows it.

## Venue
Live account. **Stages every entry** - it writes a ticket and waits for a click.
Nothing here places an order by itself.

## The one idea underneath every setup
Wait for the pullback, because the pullback IS the stop. An entry without a level
behind it has no stop close enough to size against. This is not a preference; it is
the thing that makes the position sizeable at all.

## Setups
See `10-SETUPS.md`. Every setup names the code gate that implements it, or it is
decoration.

## Rules
See `20-RULES.md`. Risk notices are ADVISORY here, not blocks - only the hard gates
stop a trade.
