first-run setup · everything stays on this machine

Your local trading desk.

Market Forge runs entirely on this computer: a catalyst radar, live charts, a trade ticket, and a seat for an AI copilot. It connects to Alpaca for market data and (paper) trading.

Paper mode by default. Fake money, real market data. Nothing trades by itself unless you explicitly turn that on, and your API keys never leave this machine - they are written to one local file, bot/.env.

Connect Alpaca.

A free Alpaca account gives you a paper-trading key pair.

Where do I get these?
  1. Sign up free at alpaca.markets
  2. Open the Paper dashboard (toggle top-left)
  3. On the right: API Keys → Generate
  4. The secret is shown once - copy both now

How will you use it?

Optional extras.

Each unlocks one feature. All of them can be added later - skipping is fine.

Catalyst scoring (Ollama)
An LLM labels each mover signal-or-noise, 0-100. Install Ollama, then ollama pull qwen2.5:3b. Auto-entries need scores.
Voicebox
A natural local voice for spoken replies, and offline voice input. Without it: browser voice out, Chrome-only voice in.
AI copilot (claude on PATH)
Powers the COPILOT tab: chat answers, live panel building, day replays.
Discord alerts
A webhook pushes scored catalysts to your phone. Paste one or leave blank.
